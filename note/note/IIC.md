```bash
SCL、SDA两根数据线

通信半双工

多主机、多从机总线

软件寻址方式：7位或10位地址

速率模式：标准模式（100kbps）、快速模式（400kbps）、高速模式（3.4Mbps）、超快速模式（5Mbps）

输出类型：开漏输出，需外接上拉电阻

空闲状态：I2C空闲时SCL、SDA均为高。

数据有效性：
I2C通信中一个至关重要的规则是：
SCL为高电平期间，SDA上的数据必须保持稳定（不允许变化），以便接收方（无论是主设备还是从设备）能够准确采样
SCL为低电平期间，SDA线上的数据才允许发生变化，为下一个比特的传输做好准备
```
