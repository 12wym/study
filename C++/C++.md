# 基本数据类型

```bash
32位操作系统
char      8位  1字节 -128 ~ 127      0 ~ 255
short     16位 2字节 -32768 ~ 32767  0 ~ 65,535
int       32位 4字节 -2^31 ~ 2^31-1  0 ~ 2^32-1
long      32位 4字节 -2^31 ~ 2^31-1  0 ~ 2^32-1
long long 64位 8字节 -2^63 ~ 2^63-1  0 ~ 2^64-1
指针       32位 4字节                 0 ~ 4GB地址空间

64位操作系统
char      8位  1字节 -128 ~ 127      0 ~ 255
short     16位 2字节 -32768 ~ 32767  0 ~ 65,535
int       32位 4字节 -2^31 ~ 2^31-1  0 ~ 2^32-1
long      64位 8字节 -2^63 ~ 2^63-1  0 ~ 2^64-1
long long 64位 8字节 -2^63 ~ 2^63-1  0 ~ 2^64-1
指针       64位 8字节                 0 ~ 16EB地址空间

float      32位 4字节 -2^31 ~ 2^31-1  0 ~ 2^32-1
double     64位 8字节 -2^63 ~ 2^63-1  0 ~ 2^64-1
```
